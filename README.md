# Data Analyzer and Transformer Program

## Project Overview

The **Data Analyzer and Transformer Program** is a Python-based console application that allows users to input numerical data and perform various operations such as:

* Data summary generation
* Factorial calculation
* Data filtering using lambda functions
* Sorting data
* Displaying dataset statistics

This project demonstrates the use of:

* Loops
* Conditional statements
* Functions
* Recursion concepts
* Lambda functions
* Built-in Python functions
* List operations

---

## Features

### 1. Input Data

Users can enter multiple integer values separated by spaces.

### 2. Display Data Summary

Shows:

* Total number of elements
* Minimum value
* Maximum value
* Sum of all values
* Average value

### 3. Calculate Factorial

Calculates the factorial of a given number using a function.

### 4. Filter Data by Threshold

Filters and displays values greater than the threshold using a lambda function.

### 5. Sort Data

Displays:

* Ascending order
* Descending order

### 6. Dataset Statistics

Returns:

* Minimum value
* Maximum value
* Total sum
* Average value

### 7. Exit Program

Terminates the application safely.

1. Install Python 3 on your system.

3. Open terminal or command prompt.
4. Run the command:

```bash
python project4.py
```
